HyperVeil

Unlock restricted visual features on HyperOS/MIUI via ADB/Shizuku.

Advanced Textures / Blur

Force-enables the Advanced Textures option in Settings > Display, along with background blur support.

service call miui.mqsas.IMQSNative ... setprop persist.sys.background_blur_supported / advanced_visual_release / computility.cpulevel+gpulevel
May cause visual glitches/lag on some devices (especially lower-end models). Turning it off restores your original values.

Icon Animations

Raises the open/close animation level for app icons (v:1,c:3,g:3).

settings put system deviceLevelList v:1,c:3,g:3

Hide Home Screen App Labels

Hides the text labels under icons on the home screen.

settings put system miui_home_no_word_model 1

Show Touches

Shows a visual dot wherever you touch the screen. Handy for screen recordings and demos.

settings put system show_touches 1

Stay Awake While Charging

Keeps the screen on whenever the phone is plugged in (AC, USB or wireless). Useful for dashboards, navigation and long installs.

settings put global stay_on_while_plugged_in 7

Ad-Blocking Private DNS

Sets system-wide Private DNS to AdGuard (dns.adguard-dns.com) to block ads and trackers in every app, no VPN needed.

settings put global private_dns_specifier dns.adguard-dns.com; private_dns_mode hostname
Turning it off sets Private DNS back to Automatic. Any custom DNS you had set before will not be restored.

Force Resizable Apps

Lets apps that normally refuse split-screen or freeform windows be resized anyway.

settings put global force_resizable_activities 1
Needs a reboot to take effect. Some apps may glitch or crash when forced to resize.
